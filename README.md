# EL Markdown and GitHub Wiki Practical

A practical project demonstrating Markdown formatting, GitHub repository management, and Wiki documentation.

## Features

- Markdown headings and paragraphs
- Bold and italic text
- Code examples
- Links and lists
- Task lists
- GitHub Wiki documentation
- Code of Conduct
- Organized repository structure
- Meaningful commit history

## Installation

Clone this repository:

```bash
git clone https://github.com/anubose1002-ai/EL-Markdown-Wiki-Practical.git
```

Navigate to the project directory:

```bash
cd EL-Markdown-Wiki-Practical
```
